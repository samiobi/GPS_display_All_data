# GPS_display_All_data
# 🛰️ مشروع تتبع GPS باستخدام Arduino Mega وشاشة OLED

مرحبًا بكم في هذا المشروع العملي الذي يهدف إلى بناء نظام تتبع GPS باستخدام لوحة **Arduino Mega**، مع وحدة **GPS** (مثل Neo-6M)، وشاشة **OLED** لعرض البيانات الجغرافية لحظيًا.

هذا المشروع مثالي للمبتدئين والمهتمين بالإلكترونيات وتطبيقات إنترنت الأشياء (IoT)، ويعزز فهمك لتكامل الحساسات مع المتحكمات الدقيقة.

## ⚙️ مكونات المشروع:
- Arduino Mega  
- وحدة GPS (مثل NEO-6M)  
- شاشة OLED 1.3" I2C  
- Breadboard + أسلاك توصيل  
- مصدر طاقة (بطارية أو USB)

---

## 🧠 ما يقدمه المشروع:
- قراءة بيانات الموقع (Latitude & Longitude)  
- حساب السرعة والوقت بدقة  
- عرض البيانات مباشرة على شاشة OLED  
- تطبيق عملي لفهم بروتوكول NMEA

---

## 💾 ملفات المشروع:
- `gps_oled_display.ino` – كود Arduino لقراءة البيانات من وحدة GPS وعرضها  
- `wiring_diagram.png` – رسم توضيحي لتوصيل الأسلاك  
- `README.md` – هذا الملف التوضيحي

---

## 🛠️ التوصيل السريع:
- GPS TX → Arduino Mega RX1 (Pin 19)  
- OLED SDA → Pin 20 (SDA)  
- OLED SCL → Pin 21 (SCL)  
- تأكد من توصيل GND وVCC بشكل صحيح لجميع المكونات

---

## 🧪 النتيجة النهائية:
ستظهر معلومات الموقع والسرعة والوقت بشكل مباشر على الشاشة الصغيرة OLED بمجرد تشغيل النظام، ويمكن تطويره لاحقًا ليشمل تخزين البيانات، أو إرسالها عبر LoRa أو Bluetooth.
